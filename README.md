# Deep Learning for Visual Anomaly Detection

Practical implementations of deep learning models for image classification, representation learning, and generative modeling, developed as part of my Master's studies in Mechatronic Engineering.

## Implementations

### 1. Image Classification
**Notebook:** `classifiers/Lab01_Classifiers_AlbanM.ipynb`

Implementation and evaluation of image classification approaches using the PlantVillage dataset.

### 2. Autoencoder
**Notebook:** `autoencoders/Lab03_Autoencoder_AlbanM.ipynb`

Implementation of an autoencoder for learning compact image representations and exploring reconstruction-based approaches.

### 3. Generative Adversarial Network (GAN)
**Notebook:** `GANsvg/Lab04_GAN.ipynb`

Implementation of a generative adversarial network to explore deep generative modeling.
